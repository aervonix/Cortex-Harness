# What the independent review found, on 2026-11-13

A fresh reviewer on Opus read the whole change (`f24c001..da2191d`) against the specification, before the first push. Its findings, at the coordinator's bar (fix what lets a sandboxed command do what the policy forbids, what reports a weaker sandbox as stronger, or what breaks the done criteria; put the rest in `docs/outstanding/`), and what was done:

| # | Finding | What was done |
|---|---|---|
| 1 | **Undo wrote through links a confined command planted.** A command that swapped `.git` for a link to `~/.ssh` had undo write the old git configuration there. | **Fixed in `cortex-session`:** a file whose directory on the way, or which itself, is a link when it is put back is left and reported (`snapshot::through_a_link`), and the write never follows a link. The look does not look through a linked directory either. Tests: `snapshot::tests::a_path_reached_through_a_link_is_not_put_back`, `sandbox::sys_undo_does_not_write_through_a_link_a_command_planted`, `protect::tests::a_linked_git_directory_is_not_looked_through`. |
| 2 | **A change made between two looks became the next baseline:** a process that left the tree with `setsid` wrote a hook after the look; and commands marked as only reading were not looked at. | **Fixed:** `setsid` and `setpgid` are answered as done without being done, so every process stays in the command's group and dies with it; every confined command is looked at. Test: `confined::sys_the_calls_that_would_undo_or_get_round_the_sandbox_are_refused` (`same` inside, `new` outside). |
| 3 | **"The turn stops" did not hold within one response:** a call decided or approved before the stop still ran. | **Fixed:** the core's shell wrapper runs no command of a stopped turn, and an answer to a question open at the stop is a stop.
