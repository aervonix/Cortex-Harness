| **Signals and a graceful shutdown in the interactive application.** The terminal layer's handlers for SIGTERM, SIGHUP, SIGINT and SIGQUIT, and its console control handler, put the terminal back and then let the signal end the process at once; they replace any handler installed before them, so a session log is not flushed on SIGTERM. After any emergency restore (a signal, or a panic on a thread other than the interface's) the layer refuses further writes, and the application's next frame fails. Step 23 decides what the application does: chain to a graceful shutdown on the core thread, end on a write that fails, and what a panic in a background task means for the interface (step 20's review). | Step 23 (the interactive application) | Before the first release |
