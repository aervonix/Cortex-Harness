| **The timeout report's timing on Windows.** The report of `cortex_testkit::watch` comes at four fifths of a test's limit ([testing-and-ci.md](../testing-and-ci.md), "When a test runs out of time"). On Linux that is counted from the process's start; elsewhere from the test's first wait, so a test that works for three seconds before its first gate gets its report after nextest has stopped it. And on Windows the process tree is asked of PowerShell, which on a loaded runner can take longer than the two seconds a test of tiers 1 and 2 has left; the waits are written first, so only the tree is lost then. Found by the step's independent review.
