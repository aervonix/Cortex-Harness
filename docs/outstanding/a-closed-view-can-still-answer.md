| **A client that closed its view of a session can still answer a question it was asked there.** `session/close` takes the client off the session's events and leaves it in the list of clients an open approval request was sent to, so its answer is still taken. The protocol allows it (the client was sent the request, and an answer is checked for that), but a front end that closed a session probably does not expect to settle its questions. The choice: leave it, or take a client that closes its view out of the questions it was sent, as one that disconnects already is (its answer is refused, since it is no longer a client).
