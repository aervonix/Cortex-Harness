| **A datagram socket pair can send to a local datagram socket by its path.** With the network off a confined command cannot make a socket, and can still make a connected pair (`socketpair`). A pair of datagram sockets accepts `sendto` with a path, which reaches a datagram socket of the machine's: journald's (`/run/systemd/journal/socket`), `/dev/log`, the service manager's notification socket. That is injecting lines into the system's log, not a way out of the sandbox (no stream socket is reached, so no D-Bus, agent or Docker socket), and decision 0032 says a pair reaches only the command's own processes. Found by the independent review of step 26. **Recommendation:** on Landlock 9 (Linux 7.1) handle the right that resolves a Unix socket's path, which covers this; before it, refuse `socketpair` for datagrams, after measuring what that breaks. | Step 32 (hardening pass) | Before the first release |
