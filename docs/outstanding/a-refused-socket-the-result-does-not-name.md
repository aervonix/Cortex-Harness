| **A socket the filter refuses with the network on is not named in the result.** With `sandbox.network = "off"` a failure that reads like a refused connection is explained as the network being off. With `"full"`, a Unix socket (or another family the filter does not allow) is refused with `EPERM`, and the program's message says only "Operation not permitted", sometimes with the socket's path, which the explanation can then read as a refused write to that path. The model is not told that the sandbox refused a socket, nor that a run outside it with approval is the way out. Found by the second review of step 26. **Recommendation:** when the network is on and a line reports `EPERM` next to a socket's path or a socket call, say that the sandbox refuses Unix sockets and how to leave it for one run; test it with the helper that makes each kind of socket. | Step 32 (hardening pass) | Before the first release |
