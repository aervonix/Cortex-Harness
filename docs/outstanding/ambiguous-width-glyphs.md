| **Glyphs of ambiguous width in a terminal that draws them wide (step 22's review).** Fourteen glyphs of the Unicode set are of East Asian ambiguous width: `◆ ◇ ∴ ■ · ╭ ╮ ╰ ╯ ─ │ – … →`, the box's edges among them. The layout counts them as one column, as terminals draw them outside CJK locales ([architecture/09-tui.md](../architecture/09-tui.md), "Colour and glyphs"). A terminal set to draw them wide (a CJK locale with that option, as some Linux terminals and older Windows consoles have) would widen every box row; with automatic wrap off, the terminal cuts such a row short rather than wrapping it, so the presenter's count of rows holds, but boxes lose their right edge. The choices: leave it, and document `tui.glyphs = "ascii"` for those terminals; make `tui.glyphs = "auto"` choose ASCII when the locale is Chinese, Japanese or Korean; or replace the ambiguous glyphs with ones of narrow width. | Step 23 (it declares `tui.glyphs` and builds the first-run checks), with the owner | Before the interactive alpha (step 25) |
