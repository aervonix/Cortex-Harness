# compaction

A block of a kind this build has no name for, with an addition of a kind it has no name for either: a compaction block, which starts with no content and gets all of it in one `compaction_delta`. The block is kept as a provider block, with its content, so that it can be sent back.

- Written by hand on 2026-11-13, from the provider's documentation of streaming with compaction. It was not recorded: the case cannot be provoked on demand.
- Model: `claude-haiku-5-5`. Speed asked for: `standard`.
- `request.json` is the request of a recorded fixture, standing in for the request that such a response would answer.
