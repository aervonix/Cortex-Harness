# deepseek-stop-aborted

A response that stops with `aborted`, a stop reason DeepSeek's reference lists and this build has no neutral value for. It is passed on under its own name, never taken for an ordinary end.

- **Written by hand** on 2026-11-13, from DeepSeek's API reference for the chat completion chunk, which lists `aborted` among the values of `finish_reason` (api-docs.deepseek.com/api/create-chat-completion). It was not recorded: the case cannot be provoked on demand. A recording from the real server can replace it.
- Model: `deepseek-flash`. Speed asked for: `standard`.
- `request.json` is what the request builder writes for the request such a response would answer. It was not sent to anything.
