# openai-unknown-event

A stream with things in it this build does not know: a comment, an event with a name of its own, a chunk of another kind of object, and members of a delta and of a chunk that nothing reads. All of it is skipped, and the text around it arrives whole.

- **Written by hand** on 2026-11-13, from OpenAI's API reference for the chat completion chunk object, which says that fields may be added (developers.openai.com/api); the unknown parts are made up, as unknown parts must be. It was not recorded: there was no OpenAI key, and an event nobody knows cannot be asked for. A recording from the real server can replace it.
- Model: `gpt-6-luna`. Speed asked for: `standard`.
- `request.json` is what the request builder writes for the request such a response would answer. It was not sent to anything.
